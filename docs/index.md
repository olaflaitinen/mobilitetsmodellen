# Mobilitetsmodellen

**Machine-learning estimators of intergenerational mobility in Sweden**

Department of Economics, Stockholm University | EUPL-1.2 | v0.1.0

---

Mobilitetsmodellen is a production-grade Python research-software library for estimating
intergenerational income and rank mobility in Sweden across birth cohorts and municipalities.

## Key Features

- Classical rank-rank slope and IGE estimators with cluster-robust standard errors
- Double machine learning with SHA-256-deterministic cross-fitting
- Generalised random forests via EconML for heterogeneous mobility estimation
- Causal mediation decomposing education, occupation, and parental-wealth channels
- James-Stein empirical-Bayes shrinkage for municipality-level estimates
- Interactive WCAG 2.2 AA-compliant mobility atlas
- Cross-country benchmarking against OECD IDD, US, UK, and Nordic comparators
- Full REUSE 3.0 compliance; EUPL-1.2 sole licence
